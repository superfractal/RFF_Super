## Appearance guide

Labels below identify exact catalog keys; never use labels as keys.

Scope: only listed keys are editable. HDR, effect layers and non-texture layer order/visibility are editable when listed. All texture settings and external assets are protected. Hidden layers may prevent a visible result; inspect the rendered image only when an image is attached.

Palette: colors are cyclic stops (2..64); Mandelbrot Color fills the interior. Larger Iteration Interval spreads a cycle across more iterations; Offset Ratio shifts it in cycles. Cycle Bias reshapes the cycle; 1 is neutral. Cycle Curve: 0 power,1 wave. Iteration Coloring: 0 linear,1 square root,2 cube root,3 log,4 log-log,5 smoothstep,6 smootherstep. Preserve intervals unless band spacing should change. Animation Speed moves colors; Flow Amount adds animated distortion, Scale controls its spatial detail, Speed its rate, Swirl its curl. Static Color Tolerance affects matching preserved colors, not overall saturation.

Stripe: Type 0 none,1 single direction,2 smooth,3 squared. Intervals set stripe spacing; Opacity mixes stripes; Offset shifts them; Animation Speed moves them. Set Type and Opacity together when adding stripes.

Lighting: Shading Depth strengthens relief and can saturate quickly; preserve it unless relief is requested. Opacity mixes shading, Shadow Floor lifts dark areas. Zenith/Direction and other light angles are degrees. Specular Intensity controls highlights; higher Power narrows them. Specular angles require Independent=true. Anisotropy stretches highlights; Angle rotates the stretch. Rim Intensity lights edges; Power shapes the rim. AO darkens recesses; AO Radius widens sampling. Ambient mixes Sky/Ground tints; Fill lifts shadows from its own direction. Macro Relief mixes broad form, Macro Radius sets its scale. Relief Response moves highlights from anchored to surface tilt (0..1). Terminator Softness softens the light/shadow boundary. Luma Amount=0 removes brightness shading; Tint Response>1 confines tint toward light; Shadow Chroma requires OKLab tint mode. Highlight Knee shapes highlight rolloff.

Studio: Roughness up broadens/dulls reflections (try .2.. .5); Metalness up makes metallic reflection; IOR controls dielectric reflectance, not transparency. Direct Light and Studio Reflections are independent strengths. Clearcoat adds a top highlight; Coat Roughness controls its spread. Studio numeric edits enable studio; surface.studio.enabled is applied last. Environment Rotation rotates reflections; Follow Light Direction mixes light tracking. Iridescence needs nonzero strength to show Film Thickness (nm). Specular Antialiasing softens unstable highlights; Boundary Reflection Guard reduces boundary artifacts.

Surface: style selects a recipe, resetting mixes and band-line settings before your overrides; use only for a requested style change. Reflection Detail/Contrast/Brightness/Curvature shape reflected detail, contrast, gain and curvature. Thin Film Color, Rainbow Width/Spread and Film Hue control decorative rainbow reflections; Glint Strength/Size control sparkles. Surface Phase shifts surface variation. Palette Color retains palette contribution; Surface/Reflection/Background Color Amount mix their corresponding colors; Preserve Palette Ink retains palette ink. Changing these colors may enable their mix and disable black-metal monochrome or print flatness.

Style groups: Chrome Flames/Shadow Crush/Red-Purple/Surface Damage shape PHONK; Frost Strength/Threshold shape frost; Sea Glow/Threshold/Body/Particles/Particle Size/Balance shape sea emission. Detail Light adds fine light; Dense Detail Suppression reduces dense highlights above Detail Density Threshold. Print Color Count quantizes to 3..6 colors; Flatness, Tone Balance, Wave Foam and Woodcut Grain shape print shading. Print color edits can raise Color Count. VHS Damage adds noise, Chromatic Shift separates channels, Nearest Mix/Block Size pixelate, Film Grain adds grain, Monochrome removes color. These finish controls do NOT auto-enable their groups: set layerVhs, layerMono or layerQuantize explicitly as needed. Layer mixes=0 suppress their added contribution; an active style can still contribute. Lustre Depth needs Lustre Relief enabled. Normal Smoothing softens normals; Relief Waves/Frequency add relief modulation.

Color: Gamma=1 neutral, higher brightens midtones. Exposure=0 neutral and uses (1+x)/(1-x), NOT photographic stops; stay well below 1 (start -.2.. .2). Hue is degrees; Saturation/Brightness/Contrast=0 neutral, positive increases each. Start with small changes, not range extremes.

Fog: Opacity controls fog blur, Radius its extent. Center Start=0 whole frame,1 edge; Invert swaps center/edge falloff. Rim Mask confines fog to rim lighting; Boost strengthens that mask; Rim Blur softens it. Focus Amount controls depth blur based on iteration count, NOT camera distance. Focus Ratio=0 shallow,1 interior edge; Range is sharp-band half-width; higher Falloff holds more sharpness. Focus Blur/Rim Blur use pixels relative to width 1280. Chaos Amount blurs irregular detail; Threshold selects it, Transition/Feather soften its mask, Blur Radius controls blur, Highlight Detail preserves bright detail, Shade darkens it. For crisp output set fog Opacity, Focus Amount and Chaos Amount=0.

Bloom: Threshold selects bright sources (higher selects fewer), Radius spreads glow, Softness softens it, Intensity controls strength (start .05.. .4). Intensity=0 removes bloom, not material emission; also reduce Sea Glow/Detail Light/Glints if those cause unwanted glow.

Pattern/Warp shared UV Mode: 0 cycle+angle,1 cycle+screen,2 screen,3 cycle+band direction. Scale U/V count repeats (higher=finer); Scroll U/V are repeats/sec; Palette Follow=1 follows palette animation,0 stays fixed,negative reverses. Period Iterations=0 follows palette cycle length; positive sets independent spacing. Pattern Blend Mode: 0 multiply (darkens),1 overlay,2 replace. Opacity mixes coverage; Enabled must be true. Texture settings are unavailable.

Pattern needs no image and affects exterior only. Type: 0 stripes,1 checker,2 grid,3 dots,4 diamond,5 honeycomb,6 waves,7 cloud. Ink Mode: 0 solid Color,1 shifted palette. Palette Shift is cycles (.5 opposite side); Sharpness=0 soft,1 hard. Edge Enabled adds Edge Color at Edge Opacity; Width sets seam half-thickness in shape-field units, not pixels (negative can thin soft seams). Edge Relative normalizes width to the shape peak. Each of four layers can have independent settings.

Warp: Enabled and Amount control coordinate displacement; start small to preserve detail. Source: use 0 procedural noise; external textures are protected. Octaves adds noise detail. Prefer noise when no image is known.
